# 🏡 NESTORA – PG & Hostel Management Website

**Your Home Away From Home**

🌐 **Live Website:** https://bhanumadhavm-design.github.io/nestora/

## 📌 About the Project

NESTORA is a modern, responsive PG and hostel management website designed to help students and working professionals explore accommodation options.

The website provides information about available rooms, facilities, food menus, hostel rules, complaint support, and contact details through a clean and user-friendly interface.

## ✨ Features

- **Home Page:** Attractive hero section introducing the hostel.
- **About Section:** Information about NESTORA.
- **Room Details:** Four-sharing, two-sharing, and single-sharing room options with sample monthly prices.
- **Facilities:** Wi-Fi, healthy food, laundry, security, hot water, and housekeeping.
- **Food Menu:** Weekly breakfast, lunch, and dinner schedules.
- **Hostel Rules:** Guidelines for residents.
- **Complaint & Support:** Contact options for maintenance issues, food feedback, and general support.
- **Contact Section:** Address, phone number, email, and enquiry form.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/bhanumadhavm-design/nestora.git
   ```

2. Open the project folder:

   ```bash
   cd nestora
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code.
